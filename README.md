# 🐠 aqua-care-pro
## 나만의 픽셀 어항 꾸미기 & AquaCare Pro

사용자가 직접 어항을 꾸미고, 어종별 사육 환경을 진단하며, 물생활에 필요한 정보를 확인할 수 있는 Streamlit 기반 웹 애플리케이션입니다.

---

## 1. 프로젝트 소개

**AquaCare Pro**는 초보자도 쉽고 재미있게 어항을 관리할 수 있도록 제작한 웹 애플리케이션입니다.

픽셀 그래픽을 활용한 나만의 어항 꾸미기 기능과 어종별 사육 환경 진단, 물생활 Q&A 및 계산 기능을 제공합니다.

사용자는 다양한 생물과 장식물을 배치하고, 어항 환경을 설정하며, 물고기 사육에 필요한 정보를 확인할 수 있습니다.

## 2. 프로젝트 주요 페이지

### ① 나만의 픽셀 어항 꾸미기

- 픽셀 그래픽을 활용한 나만의 어항 만들기
- 물고기와 다양한 생물 배치
- 모래, 암석, 수초 등 바닥재 및 장식 배치
- 조명과 수온 조절
- 물고기 먹이 주기
- 다양한 도구를 활용한 어항 관리
- 어항 환경에 따른 시각적 변화

### ② AquaCare Pro - 어항 환경 진단

- 담수어, 해수어, 열대어 등 어종 선택
- 여러 어종을 동시에 선택하는 기능
- 어항의 총 개체 수와 수조 용량 설정
- 현재 사육 수온 조절
- 어종에 따른 적정 수온 확인
- 수온을 반영한 적정 사료량 계산
- 어종별 합사 가능 여부 확인
- 수조 과밀 여부 진단
- 수질 및 환경 관리 가이드
- 어종별 질병 예찰 및 주의사항 안내

### ③ 어항선배 - 초보자를 위한 물생활 Q&A

- 물잡이 및 환수 관련 질문
- 먹이 및 급여 방법 안내
- 어종별 합사 및 생물 관리 정보
- 질병 및 돌발 상황 대처 정보
- 어항 장비 및 세팅 관련 정보
- 총 50가지 질문과 답변 제공
- 질문 선택에 따른 상담 대화 기록
- 대화 기록 초기화 기능
- 관련 참고 검색 링크 제공

### ④ 어항 관리 계산 및 일정 기능

- 어종별 합사 가능성 진단
- 어항 가로, 세로, 높이를 이용한 물용량 계산
- 실제 물 용량 추정
- 권장 환수량 계산
- 30일 물잡이 가이드 일정 제공

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 어항 꾸미기 | 픽셀 그래픽으로 나만의 어항 제작 |
| 생물 배치 | 다양한 물고기와 생물 배치 |
| 환경 설정 | 담수 및 해수 환경 선택 |
| 조명 조절 | 어항 조명 설정 |
| 수온 조절 | 어항의 수온 설정 |
| 사료량 계산 | 수온에 따른 추천 사료량 계산 |
| 합사 진단 | 어종별 합사 위험 확인 |
| 과밀도 진단 | 수조 용량 대비 사육 환경 확인 |
| 물생활 Q&A | 초보자를 위한 50가지 질문과 답변 |
| 물용량 계산 | 수조 크기에 따른 물 용량 계산 |
| 물잡이 가이드 | 30일 물잡이 일정 안내 |

## 4. 사용 기술

- **Python**: 프로그램의 기본 기능 구현
- **Streamlit**: 웹 애플리케이션 제작 및 화면 구성
- **HTML**: 어항 화면 및 웹 요소 구성
- **CSS**: 디자인 및 애니메이션 효과 구현
- **JavaScript**: 픽셀 어항의 상호작용 및 움직임 구현

## 5. 실행 방법

1. Python을 설치합니다.
2. 필요한 라이브러리를 설치합니다.

```bash
pip install streamlit
```

3. 프로젝트 폴더에서 실행합니다.

```bash
streamlit run app.py
```

4. 브라우저에서 실행된 웹 애플리케이션을 확인합니다.

## 6. 프로젝트 목적

물고기를 키우는 과정에서 발생할 수 있는 다양한 고민을 해결하고, 초보자도 쉽게 어항을 꾸미고 관리할 수 있도록 돕는 것이 프로젝트의 목적입니다.

단순한 어항 꾸미기를 넘어 생물의 사육 환경과 물생활 정보를 함께 제공하여 재미와 실용성을 갖춘 어항 관리 플랫폼을 만드는 것을 목표로 합니다.

## 7. 기대 효과

- 어항 꾸미기를 통한 창의적인 활동 경험
- 어종별 사육 환경에 대한 이해 향상
- 물고기 먹이 및 수질 관리 정보 습득
- 초보자의 물생활 입문 지원
- 어항 관리에 필요한 정보의 편리한 확인
