# aqua-care-pro
# 🐠 나만의 픽셀 어항 꾸미기

## 1. 프로젝트 소개

**나만의 픽셀 어항 꾸미기**는 사용자가 직접 어항을 꾸미고 다양한 생물과 장식물을 배치할 수 있는 웹 애플리케이션입니다.

픽셀 그래픽을 활용하여 나만의 어항을 만들 수 있으며, 담수와 해수 환경을 선택하여 원하는 분위기의 어항을 구성할 수 있습니다.

## 2. 사용법

1. 앱을 실행합니다.
2. 담수 또는 해수 환경을 선택합니다.
3. 파우더, 생물, 장비 중 원하는 도구 모드를 선택합니다.
4. 원하는 생물이나 장식물을 선택합니다.
5. 어항 화면에서 마우스로 클릭하거나 드래그하여 배치합니다.
6. 조명과 수온을 조절하여 어항을 꾸밉니다.
7. 먹이를 주거나 다양한 도구를 사용하여 어항을 관리합니다.

## 3. 주요 기능

- **환경 선택:** 담수 및 해수 어항 환경 선택
- **생물 배치:** 다양한 종류의 물고기와 수중 생물 배치
- **바닥재 꾸미기:** 모래, 암석 등 다양한 바닥재 배치
- **수초 꾸미기:** 수초와 장식물 배치
- **장비 배치:** 기포기와 히터 등 어항 장비 배치
- **조명 조절:** 어항 조명 켜기 및 끄기와 색상 변경
- **수온 조절:** 슬라이더를 이용한 어항 수온 조절
- **어항 관리:** 먹이 주기와 어항 초기화 기능

## 4. 실행 방법

### 사용 기술
- Python
- Streamlit
- HTML
- CSS
- JavaScript

### 실행 순서

1. Python을 설치합니다.
2. 터미널에서 Streamlit을 설치합니다.

```bash
pip install streamlit
```

3. 프로젝트 폴더로 이동합니다.
4. 다음 명령어를 실행합니다.

```bash
streamlit run pages/2_나만의_어항_꾸미기.py
```

5. 브라우저에서 실행된 어항 애플리케이션을 확인합니다.
